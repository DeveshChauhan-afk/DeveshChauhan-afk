## 🚀 Featured Projects

### 🛡️ SentinelGraph AI

**Fraud Intelligence Graph for Digital Public Safety**

An AI-powered digital public safety platform that transforms complaints into connected fraud intelligence. It combines **Graph RAG, Neo4j graph reasoning, deterministic risk scoring, and Gemini-powered investigation** to help uncover relationships and potential fraud networks.

**Tech:** FastAPI • PostgreSQL • Neo4j • Gemini • React • TypeScript • Docker • Prometheus • Grafana

**Repository:** https://github.com/DeveshChauhan-afk/sentinelgraph-ai

---

### 🏨 Hotel Management System

A full-stack hotel management platform designed around a structured backend architecture for managing **rooms, bookings, users, authentication, and administrative operations**.

The system uses Flask with a relational database and includes **role-based access control, JWT authentication, password hashing, rate limiting, SQLAlchemy models, and a modular backend architecture**.

**Tech:** Python • Flask • MySQL • SQLAlchemy • JWT • Flask-Login

**Repository:** https://github.com/DeveshChauhan-afk/hotel-management-system

---

### 🏃 Human Activity Recognition

An end-to-end machine learning and deep learning system that classifies human activities using **smartphone sensor data**.

The project explores both classical machine learning and neural-network approaches while covering data preprocessing, feature engineering, model training, evaluation, and prediction.

**Tech:** Python • TensorFlow • Scikit-learn • Pandas • Machine Learning

**Repository:** https://github.com/DeveshChauhan-afk/HARUS-Project
